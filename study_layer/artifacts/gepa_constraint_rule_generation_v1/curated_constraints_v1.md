# Curated Constraint Candidates v1

These are tightened from the Qwen constraint pass. The actual rule text now includes concrete surface examples because those examples are part of the intervention: they teach the model what kind of table/cell situation the rule means.

Count: `13`

- `wtq.row_order_anchor_navigation` [private_reasoning_rule, risk=low]: If the question asks for a previous/next/before/after item, such as "which title is listed previous to O Janewale" or "what was before X", first locate the anchor row by exact cell match, then move by displayed row order and project the requested column; do not sort by a value column unless the question explicitly says highest/lowest/max/min. Trigger: question contains previous/next/before/after/directly before/directly after and names an anchor cell, e.g. previous to O Janewale, before Tignes, after Miss World
- `wtq.identifier_name_role_binding` [domain_heuristic, risk=low]: If the requested answer is a name/title/entity role, such as ship name, episode title, team, player, school, route name, or symbol name, select the name/title/entity column; never output an identifier, code, number, rank, glyph, seed, or position column unless the question explicitly asks for that identifier role. Trigger: question asks for name/title/team/player/ship/school/route/symbol and table also has id/code/no./rank/seed/position/glyph columns
- `wtq.rank_direction_not_arithmetic` [private_reasoning_rule, risk=medium]: If the target column is rank/place/position/seed/pick/chart position, including chart columns such as GER/UK/US peak position, treat it as an ordinal where smaller usually means earlier/better; do not add, average, or compare it as a magnitude unless the question explicitly asks arithmetic over ranks. Trigger: headers or question contain rank/place/position/seed/pick/chart position or compact chart-country headers such as GER peak
- `wtq.score_atomic_vs_margin` [domain_heuristic, risk=low]: If a sports/match/game table has score/result cells like 18-12, 14-14, 58-13, or 2-1 and the question asks for the result/score, return the complete score string exactly as the table gives it; split or subtract the score only when the question asks for margin, difference, winner side, loser side, total, or comparison. Trigger: sports/match/game table with score/result cells such as 18-12, 14-14, 58-13, 2-1
- `sqa.active_set_first` [task_heuristic, risk=low]: For follow-up wording that refers to prior answers, such as these ships, of these, those countries, their titles, among them, or which one, first restrict candidate rows to the previous answer set; do not scan the whole table until this active-set filter has been applied. Trigger: SQA position>0 and question contains these/those/their/of these/of those/among them/which one/of them, e.g. of these ships or their titles
- `sqa.project_requested_role_after_history` [task_heuristic, risk=low]: After resolving active rows from history, project only the newly requested column or role, such as cost from Est. building cost, country from Country, or date from Launched; do not repeat the previous answer role, return the matched value, or return whole rows. Trigger: SQA follow-up asks for an attribute/property after prior entity set is established, e.g. of these ships which had highest cost
- `sqa_one_answer_per_active_item` [response_contract, risk=medium]: If the question asks one property for each active item, such as their dates, these teams, which ones, or what countries, output one answer per active item in active-set order; do not collapse duplicates or stop after the first matching row. Trigger: SQA follow-up asks each/their/which ones/what dates/what countries over a multi-item active set
- `tablebench_bind_metric_before_operation` [private_reasoning_rule, risk=low]: Before any numeric operation, bind the exact metric column named by the question, including unit and year qualifiers, such as GDP per capita as of 2012 (PPP), population density (/ km2), floors, or gap from Thailand; do not compute over a neighboring metric column with similar numbers. Trigger: TableBench numerical question asks highest/lowest/average/sum/difference over a named metric column, e.g. GDP per capita as of 2012 or population density
- `tablebench_aggregation_scope_all_rows` [private_reasoning_rule, risk=low]: For average/sum/total questions, such as average population density of all municipalities or average floors from 1895 to 1980, enumerate all rows satisfying the stated filters, then aggregate exactly those rows; do not aggregate only visible preview rows, headers, totals, or examples. Trigger: question asks average/sum/total over all rows or over a filtered subset, e.g. all municipalities or constructed from 1895 to 1980
- `tablebench_rank_select_entity_not_value` [private_reasoning_rule, risk=low]: If the question asks which/who/economy/entity has an extreme metric, such as which economy had the highest GDP per capita as of 2012, sort/filter by the metric column but return the entity column, e.g. Singapore; do not return the numeric metric value unless the question asks for the value. Trigger: question asks which/who/economy/entity had highest/lowest metric, e.g. which economy had highest GDP per capita
- `hitab_header_path_cell_binding` [domain_heuristic, risk=low]: Before selecting a HiTab cell, resolve its full row-header path and column-header path, including parent group labels and unit rows such as for thousand women, fiscal year, R&D expenditure, cases, percentage, or population; do not compare or project a cell using only its leaf header. Trigger: HiTab/statistical table with parent headers, subheaders, or table_source in {statcan, nsf, totto}, e.g. StatCan fertility rate by age group
- `hitab_pair_comparison_preserve_label` [private_reasoning_rule, risk=low]: For pairwise comparison questions, such as Quebec or Ontario, experienced enterprises or total average, higher/lower/more/less, compare only the two named candidates under the same indicator and unit, then return the winning candidate label from the table; do not return the compared numeric cell unless the question asks for the value. Trigger: HiTab aggregation contains pair-argmax/pair-argmin or question asks which of A or B is higher/lower/more/less, e.g. Quebec or Ontario
- `hitab_signed_formula_surface` [private_reasoning_rule, risk=medium]: If the referenced value or answer formula is negative, such as answer formula =-B6 or a table cell -630, preserve the sign exactly unless the question asks for an absolute magnitude; do not strip, invert, or explain away the sign. Trigger: HiTab answer formula or table cell contains a leading negative sign, e.g. =-B6 or -630
