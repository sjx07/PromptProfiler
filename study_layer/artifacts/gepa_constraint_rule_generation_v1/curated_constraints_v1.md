# Curated Constraint Candidates v1

These are tightened from the Qwen constraint pass. They are still hypotheses, but the wording is closer to FACET prompt-feature candidates: explicit trigger, required action, and forbidden action.

Count: `13`

- `wtq.row_order_anchor_navigation` [private_reasoning_rule, risk=low]: If the question asks for a previous/next/before/after item, first locate the anchor row by exact cell match, then move by displayed row order and project the requested column; do not sort by a value column unless the question explicitly says highest/lowest/max/min. Trigger: question contains previous/next/before/after/directly before/directly after and names an anchor cell
- `wtq.identifier_name_role_binding` [domain_heuristic, risk=low]: If the requested answer is a name/title/entity role, select the name/title/entity column; never output an identifier, code, number, rank, glyph, seed, or position column unless the question explicitly asks for that identifier role. Trigger: question asks for name/title/team/player/ship/school and table also has id/code/no./rank/seed/position columns
- `wtq.rank_direction_not_arithmetic` [private_reasoning_rule, risk=medium]: If the target column is rank/place/position/seed/pick/chart position, treat it as an ordinal where smaller usually means earlier/better; do not add, average, or compare it as a magnitude unless the question explicitly asks arithmetic over ranks. Trigger: headers or question contain rank/place/position/seed/pick/chart position
- `wtq.score_atomic_vs_margin` [domain_heuristic, risk=low]: If the question asks for a result/score cell, return the complete score string exactly as the table gives it; split or subtract the score only when the question asks for margin, difference, winner side, loser side, total, or comparison. Trigger: sports/match/game table with score/result cells such as 18-12 or 14-14
- `sqa.active_set_first` [task_heuristic, risk=low]: For follow-up wording that refers to prior answers, first restrict candidate rows to the previous answer set; do not scan the whole table until this active-set filter has been applied. Trigger: SQA position>0 and question contains these/those/their/of these/of those/among them/which one/of them
- `sqa.project_requested_role_after_history` [task_heuristic, risk=low]: After resolving the active rows from history, project only the newly requested column or role; do not repeat the previous answer role, return the matched value, or return whole rows. Trigger: SQA follow-up asks for an attribute/property after prior entity set is established
- `sqa_one_answer_per_active_item` [response_contract, risk=medium]: If the question asks one property for each active item, output one answer per active item in active-set order; do not collapse duplicates or stop after the first matching row. Trigger: SQA follow-up asks each/their/which ones/what dates over a multi-item active set
- `tablebench_bind_metric_before_operation` [private_reasoning_rule, risk=low]: Before any numeric operation, bind the exact metric column named by the question, including unit and year qualifiers; do not compute over a neighboring metric column with similar numbers. Trigger: TableBench numerical question asks highest/lowest/average/sum/difference over a named metric column
- `tablebench_aggregation_scope_all_rows` [private_reasoning_rule, risk=low]: For average/sum/total questions, enumerate all rows satisfying the stated filters, then aggregate exactly those rows; do not aggregate only visible preview rows, headers, totals, or examples. Trigger: question asks average/sum/total over all rows or over a filtered subset
- `tablebench_rank_select_entity_not_value` [private_reasoning_rule, risk=low]: If the question asks which entity has an extreme metric, sort/filter by the metric column but return the entity column; do not return the numeric metric value unless the question asks for the value. Trigger: question asks which/who/economy/entity had highest/lowest metric
- `hitab_header_path_cell_binding` [domain_heuristic, risk=low]: Before selecting a HiTab cell, resolve its full row-header path and column-header path, including parent group labels and unit rows; do not compare or project a cell using only its leaf header. Trigger: HiTab/statistical table with parent headers, subheaders, or table_source in {statcan, nsf, totto}
- `hitab_pair_comparison_preserve_label` [private_reasoning_rule, risk=low]: For pairwise comparison questions, compare only the two named candidates under the same indicator and unit, then return the winning candidate label from the table; do not return the compared numeric cell unless the question asks for the value. Trigger: HiTab aggregation contains pair-argmax/pair-argmin or question asks which of A or B is higher/lower/more/less
- `hitab_signed_formula_surface` [private_reasoning_rule, risk=medium]: If the referenced value or answer formula is negative, preserve the sign exactly unless the question asks for an absolute magnitude; do not strip, invert, or explain away the sign. Trigger: HiTab answer formula or table cell contains a leading negative sign
