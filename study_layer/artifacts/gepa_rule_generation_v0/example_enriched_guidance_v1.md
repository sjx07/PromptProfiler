# Example-Enriched Guidance Rules v1

This companion artifact keeps the guidance-style form but includes concrete surface examples inside the rule text. The examples are intentional context-learning anchors, not just metadata.

Count: `13`

- `wtq_row_order_anchor_navigation_guidance`: When the question asks for a previous/next/before/after item, such as "which title is listed previous to O Janewale" or "what was before X", first locate the anchor row by exact cell match, then move by displayed row order and project the requested column; avoid sort by a value column unless the question explicitly says highest/lowest/max/min. Examples: O Janewale
- `wtq_identifier_name_role_binding_guidance`: When the requested answer is a name/title/entity role, such as ship name, episode title, team, player, school, route name, or symbol name, select the name/title/entity column; never output an identifier, code, number, rank, glyph, seed, or position column unless the question explicitly asks for that identifier role. Examples: none
- `wtq_rank_direction_not_arithmetic_guidance`: When the target column is rank/place/position/seed/pick/chart position, including chart columns such as GER/UK/US peak position, treat it as an ordinal where smaller usually means earlier/better; avoid add, average, or compare it as a magnitude unless the question explicitly asks arithmetic over ranks. Examples: GER
- `wtq_score_atomic_vs_margin_guidance`: When a sports/match/game table has score/result cells like 18-12, 14-14, 58-13, or 2-1 and the question asks for the result/score, return the complete score string exactly as the table gives it; split or subtract the score only when the question asks for margin, difference, winner side, loser side, total, or comparison. Examples: 18-12, 14-14, 58-13, 2-1
- `sqa_active_set_first_guidance`: For follow-up wording that refers to prior answers, such as these ships, of these, those countries, their titles, among them, or which one, first restrict candidate rows to the previous answer set; avoid scan the whole table until this active-set filter has been applied. Examples: these ships
- `sqa_project_requested_role_after_history_guidance`: After resolving active rows from history, project only the newly requested column or role, such as cost from Est. building cost, country from Country, or date from Launched; avoid repeat the previous answer role, return the matched value, or return whole rows. Examples: these ships
- `sqa_one_answer_per_active_item_guidance`: When the question asks one property for each active item, such as their dates, these teams, which ones, or what countries, output one answer per active item in active-set order; avoid collapse duplicates or stop after the first matching row. Examples: none
- `tablebench_bind_metric_before_operation_guidance`: Before any numeric operation, bind the exact metric column named by the question, including unit and year qualifiers, such as GDP per capita as of 2012 (PPP), population density (/ km2), floors, or gap from Thailand; avoid compute over a neighboring metric column with similar numbers. Examples: GDP per capita as of 2012, population density
- `tablebench_aggregation_scope_all_rows_guidance`: For average/sum/total questions, such as average population density of all municipalities or average floors from 1895 to 1980, enumerate all rows satisfying the stated filters, then aggregate exactly those rows; avoid aggregate only visible preview rows, headers, totals, or examples. Examples: population density
- `tablebench_rank_select_entity_not_value_guidance`: When the question asks which/who/economy/entity has an extreme metric, such as which economy had the highest GDP per capita as of 2012, sort/filter by the metric column but return the entity column, e.g. Singapore; avoid return the numeric metric value unless the question asks for the value. Examples: GDP per capita as of 2012
- `hitab_header_path_cell_binding_guidance`: Before selecting a HiTab cell, resolve its full row-header path and column-header path, including parent group labels and unit rows such as for thousand women, fiscal year, R&D expenditure, cases, percentage, or population; avoid compare or project a cell using only its leaf header. Examples: none
- `hitab_pair_comparison_preserve_label_guidance`: For pairwise comparison questions, such as Quebec or Ontario, experienced enterprises or total average, higher/lower/more/less, compare only the two named candidates under the same indicator and unit, then return the winning candidate label from the table; avoid return the compared numeric cell unless the question asks for the value. Examples: Quebec or Ontario
- `hitab_signed_formula_surface_guidance`: When the referenced value or answer formula is negative, such as answer formula =-B6 or a table cell -630, preserve the sign exactly unless the question asks for an absolute magnitude; avoid strip, invert, or explain away the sign. Examples: =-B6, -630
